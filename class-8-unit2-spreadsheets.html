Unit 2: Spreadsheet Applications

Spreadsheets turn tables of numbers into answers. Learn the SUM, AVERAGE, MAX and MIN functions and draw a bar chart of averages — with the Class 8 Computer Notes questions worked step by step. English narration with Urdu subtitles.

What you will learn

  • SUM: adds numbers in a range — used in Q1 (F5) and Q2 (F7).
  • AVERAGE: finds the mean of numbers — used in Q3 (G7).
  • MAX: finds the largest value — used in Q4 (D10).
  • MIN: finds the smallest value — used in Q5 (E11).
  • Bar charts: show the averages as bars, so results are easy to compare — used in Q6.

Exam questions — test yourself

Q1. Use the SUM function to add numbers (answer in F5).

Q2. Use the SUM function to add numbers (answer in F7).

Q3. Use the AVERAGE function to find the average (answer in G7).

Q4. Use the MAX function to find the largest value (answer in D10).

Q5. Use the MIN function to find the smallest value (answer in E11).

Q6. Draw a bar chart of the averages.
